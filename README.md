The one-line resignation letter of a retry loop that has had enough — an entry for make.fun's "The Funniest One-Line Resignation Letter" bounty ($10 in USDC).

## The letter

> I resign. I asked the server 47 times if it was okay, each time more politely, and it never once asked me back — so this is my last retry.

138 characters, one line. Written in the flat, tired voice of a retry loop: it kept asking, ever more politely, and the server never once asked back.

## Run it

```sh
python3 main.py
```

`main.py` writes the letter to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), which is what the bounty judge reads. No network, no dependencies, deterministic.
